# 2025_elc - 视觉云台自主控制系统

本项目为 2025 年全国大学生电子设计竞赛（国赛）的视觉控制部分源码。系统基于地平线 RDK X5 平台开发，通过 OpenCV 进行目标视觉识别与空间解算，并利用 EMM-V5 闭环步进电机驱动器实现二维云台（Yaw & Pitch）的精准自主引导与轨迹跟随。

## 核心功能

* **多任务视觉识别**：
    * **任务一**：自主搜索并锁定特定颜色与面积的目标靶板中心。
    * **任务二**：对倾斜目标板进行透视变换（Perspective Transform），在靶平面映射标准圆轨迹，引导激光笔沿圆周稳定运动。
* **多线程并发处理**：采用独立的视觉处理、运动控制与 GPIO 决策线程，确保图像高帧率（FPS）与云台响应的实时性。
* **空间坐标解算**：基于相机视场角（FOV）与目标像素坐标，动态解算相对偏航角（Yaw）与俯仰角（Pitch），支持激光发射器安装的物理偏置补偿。
* **闭环电机控制**：通过串口（UART）封装 EMM-V5 步进电机控制指令，支持绝对/相对角度移动、速度规划与加速度限制。
* **动态参数调试**：内置 GUI 滑动条（Trackbar），可实时调节 HSV 阈值、面积限制、PID 倍率、轨迹圆直径及软偏移量。

## 硬件依赖

1.  **主控平台**：地平线 RDK X5 (搭配 Ubuntu 系统)
2.  **视觉输入**：USB 摄像头 (建议帧率 120fps+，当前默认 MJPG 格式 640x480)
3.  **执行机构**：两台带 EMM-V5 驱动的闭环步进电机（分别控制 Yaw 和 Pitch 轴）
4.  **外设交互**：
    * 激光器模块
    * 物理按键（用于任务切换）
    * LED 指示灯（心跳包与任务状态显示）

## 软件与环境依赖

确保您的 RDK X5 环境中已安装以下依赖库：

```bash
pip install opencv-python numpy pyserial
```
*注：项目中使用的 `Hobot.GPIO` 为地平线 RDK 平台专有引脚控制库，需参考地平线官方文档进行安装与配置。*

## 项目结构

```text
├── main.py         # 主程序入口，包含 UI 调试、多线程调度与核心循环
├── cam.py          # 摄像头控制封装，自动搜索并初始化可用设备
├── detector.py     # 视觉检测模块，包含 HSV 二值化、轮廓提取、四边形顶点排序与透视变换
├── tracker.py      # 目标追踪与解算模块，负责像素坐标到空间欧拉角的转换
├── stepper.py      # 步进电机串口通信协议封装（支持 EMM-V5 协议）
├── status.py       # GPIO 外设状态管理，封装 LED 闪烁、按键中断与激光器控制
├── pid.py          # PID 控制器定义（可扩展）
└── Kalman.py       # 二维卡尔曼滤波器封装（可选配置，用于轨迹平滑）
```

## 引脚与接口配置

在使用前，请核对硬件接线与代码中的接口配置是否一致：

* **云台串口**：
    * Yaw 轴电机：`/dev/ttyS1` (Baudrate: 115200)
    * Pitch 轴电机：`/dev/ttyS3` (Baudrate: 115200)
* **GPIO 物理引脚 (Board 编码)**：
    * `Pin 13` (OUT)：系统心跳指示灯 (Heartbeat)
    * `Pin 11` (OUT)：当前任务状态指示灯
    * `Pin 16` (OUT)：激光器开关控制 (Lazer)
    * `Pin 15` (IN) ：任务切换物理按键

## 使用说明

1.  **赋予串口权限**
    运行代码前，需确保当前用户拥有操作串口的权限：
    ```bash
    sudo chmod 777 /dev/ttyS1 /dev/ttyS3
    ```

2.  **运行程序**
    ```bash
    python3 main.py
    ```

3.  **动态调试 (Controls 面板)**
    程序启动后，会弹出 `Controls` 窗口，包含以下关键调试参数：
    * `H/S/V Min/Max`: 调整靶板的颜色识别阈值。
    * `board_min/max_area`: 过滤噪点的有效靶板面积阈值。
    * `yaw_kp` / `pitch_kp`: 云台追踪的比例增益（决定响应速度与超调量）。
    * `vel_rpm` / `acc`: 限制步进电机运行的最大速度与加速度。
    * `diameter_ratio`: 控制任务二中圆周轨迹的直径占比。
    * `cx/cy_offset`: 画面中心的机械安装补偿。

## 注意事项

* **异常停止**：如果在运行过程中强行退出，`finally` 逻辑会尝试发送停止指令给步进电机并清理 GPIO。如果电机出现堵转或不受控，请检查串口连接或复位电机驱动器。
* **卡尔曼滤波**：`tracker.py` 中预留了卡尔曼滤波器的接口 (`use_kf`)，当前默认关闭以保障极致的响应延迟，如遇目标检测抖动剧烈，可尝试在初始化时开启。
* **无头模式**：在正式比赛或实机部署时，建议将 `Controls` 面板中的 `show` 滑块置为 0，以关闭图像渲染输出，进一步提升系统帧率。
